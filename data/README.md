# Данные

| Набор | Где | Назначение |
|---|---|---|
| `sample/competition_demo.json` | в репозитории | синтетические соревнования для мока API и тестов |
| Таблица заказчика «Дубна_USN соревнования» | **только локально**, не в git | бэктест коллегий, карта доступности, демо |

Таблица заказчика (10 турниров 2025–2026, ответы судей, оценки экспертов ОС/КС) обезличена, но принадлежит
USN — в публичный репозиторий её не кладём. Положите файл в `data/private/` (папка в `.gitignore`) и запустите:

```bash
python data/analyze_customer_table.py data/private/Дубна_USN_соревнования.xlsx
```

Результаты проверки гипотез H-02–H-04 (08.11.2026): оценки есть у 150/150 судей из турниров;
92% ответов судей о доступности разбираются автоматически; 87% фактических назначений — в коллегию
с максимальным баллом; из 37 неполных составов 28 — ровно 7 судей.
