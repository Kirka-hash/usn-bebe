# Экраны

Кликабельный прототип — Figma, страница «Поэкранная разбивка» (режим Present ▶; старт «Участник» / «Организатор»).
Основа — бизнес-логика М. Матвеева (Miro, доска «Архитектура»).

## Участник (адаптив, 390)
| ID | Экран | Ключевые действия → переход |
|---|---|---|
| U1 | Турниры (только с открытыми ролями) | Подробнее → U3 · Войти → U2 |
| U2 | Вход / регистрация (email + код, Google) | Продолжить → U3 · Заполнить профиль → U2a |
| U2a | Профиль | Сохранить → U3 |
| U3 | Карточка турнира, сроки по ролям | нет заявки: Зарегистрироваться → U4 · есть: Моя заявка → U8 |
| U4 | Выбор роли (недоступные — серые с причиной) | роль → U5 |
| U5 | Анкета (автозаполнение из профиля) | Игрок-команда → U6a · Секундант → U6b · Судья → U6c · иначе → U7 |
| U6a | Напарник (командный) | Далее → U7 |
| U6b | Кому секундирую (несколько игроков, не себе) | Далее → U7 |
| U6c | Блоки доступности судьи, должность/компания | Далее → U7 |
| U7 | Согласия и отправка; ошибка с сохранением данных | Отправить → U8 · Ошибка → U5 |
| U8 | Моя заявка: статус, редактирование, + секундант, отзыв | Редактировать → U5 · Мои турниры → U9 |
| U9 | Мои турниры | Открыть → U8 |

## Организатор (десктоп, 1280)
| ID | Экран | Ключевые действия → переход |
|---|---|---|
| O1 | Соревнования (из API; создание — в Django Admin) | Открыть → O2 |
| O2 | Заявки: фильтры, связи, статусы | Карточка → O2a · вкладки O3/O4/O5 |
| O2a | Карточка участника: оценки ОС/КС, доступность, история | ← O2 |
| O3 | Карта доступности: судьи × блоки, доступно/нужно | Сформировать коллегии → O4 · Разобрать дефицит → O5 |
| O4 | Коллегии — предложение ИИ, пересчёт, утверждение | Почему так? → O4a · Разобрать → O5 |
| O4a | Объяснение и замены | ← O4 |
| O5 | Проблемные поединки: варианты А/Б/В, кандидаты, текст приглашения | Применить вариант → O4 |
