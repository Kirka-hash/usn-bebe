# ADR-0004: Вход участников по email с кодом на нашей стороне

**Статус:** принято (подтверждено заказчиком 08.11.2026)

**Контекст.** В Swagger USN нет методов авторизации пользователей; к API обращаемся с техническим доступом
(Basic Auth). ТЗ: вход по email или Google. Telegram-вход заказчик не рассматривает — работает нестабильно.

**Решение.** Одноразовый 6-значный код на email → сессия в нашем сервисе; наш бэкенд от имени пользователя
передаёт данные в API USN. Google-вход — отложено (спринт 3–4, если останется время).
