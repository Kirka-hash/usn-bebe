# ADR-0001: Модульный монолит + адаптер к API USN

**Статус:** принято (спринт 2)

**Контекст.** У USN работает Django-проект; ядро и Django Admin менять нельзя, доступ — только по REST API
тестовой площадки. Команда — 7 человек, знает Python; нагрузка низкая; срок — 10 недель.

**Решение.** Один сервис FastAPI с модулями `registration`, `judging`, `ai_advisor`, `notifications`;
все обращения к USN — через `integrations/usn` (интерфейс `USNClient`, реализации Mock и Http).

**Альтернативы.** Микросервисы — избыточно для команды и нагрузки. Встраивание в Django USN — нет доступа,
риск для продакшена. Только Telegram-бот — организатору нужна матрица 20–40 поединков × 9–12 судей.

**Последствия.** Можно разрабатывать на моке до доступа к стенду; изменения API заказчика правятся в одном месте.

**Проверка.** Тесты проходят на `MockUSNClient`; в спринте 3 — те же тесты против стенда.
