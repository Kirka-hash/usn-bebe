# ADR-0002: Коллегии подбирает детерминированный алгоритм, LLM только объясняет

**Статус:** принято; сравнение с LLM-подбором (H-05) — спринт 3

**Контекст.** Подбор коллегий — оптимизация с ограничениями: доступность, составы 9/7/5 и резерв,
конфликты интересов, баллы экспертов 1–3. Заказчику важно понимать, почему предложено именно так.

**Данные (H-03).** В 1610 фактических назначениях из таблицы заказчика 87% судей стоят в коллегии с
максимальным баллом; средний балл в назначенной коллегии 2,66 против 2,38 в среднем по трём коллегиям.
Эксперты совпадают в 55% оценок — объединяем средним (уточняется у заказчика, В-20).

**Решение.** Сначала жадный алгоритм (сильнейшие пары «судья–коллегия»), затем оптимизация на весь турнир
(OR-Tools). LLM получает результат и формулирует объяснения и тексты на обезличенных данных.

**Альтернатива.** Подбор целиком через LLM — невоспроизводимо, трудно проверить бэктестом.
