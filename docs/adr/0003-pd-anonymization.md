# ADR-0003: Анонимизация ПДн перед внешней LLM

**Статус:** принято

**Контекст.** Заказчик запрещает передавать ФИО и контакты во внешние LLM (встреча 21.10).

**Решение.** Шлюз `ai_advisor/anonymizer.py`: реальные имена → `JUDGE_xxx`/`PLAYER_xxx`, email и Telegram
вырезаются; таблица соответствия хранится локально (спринт 3 — PostgreSQL), ответ LLM восстанавливается.

**Проверка (H-07, спринт 3).** Автотест на 50 запросах: 0 вхождений ПДн в логах запросов к LLM.
