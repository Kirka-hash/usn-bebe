## Компоненты (`src/components/ui`)

- **Screen / ScreenHeader** — контейнер экрана (фон `#f7f7fa`, рамка, радиус 16, паддинг 20) и шапка «код + заголовок».
- **Button** — варианты `primary` (тёмно-синяя), `outline` (белая с синей рамкой), `soft` (голубая), `greenSoft` (зелёная плашка: «Подтвердить», «Утвердить распределение», «Применить вариант»), `dangerSoft` (красная), `muted` (недоступная роль, серые). Рендерит `button`, `Link` (`to`) или внешнюю ссылку (`href` + `external`).
- **Chip / ChipFilter** — плашки состояний. Ключевое: статус «Получена» — **жёлтый** (warn), «Подтверждена» — зелёный [по референсам O2/U8].
- **Note** — info / warn / err / **success** плашки (радиус 8, 12px, межстрочный 17px). Success — зелёная «Заявка принята!» на U8.
- **Field** — подпись 11px + инпут, error-состояние.
- **Checkbox** — 16px, радиус 4, синий квадрат с белой галочкой.
- **DataTable** — таблицы организатора: голубая шапка, ячейки 12px, ширины колонок из макета, горизонтальный скролл на мобильных.
- **OrganizerTabs** — таб-навигация внутри экранов O2–O5 (по референсам): активная — синяя, остальные — белые с рамкой и стрелкой «→».

## Иконки (`src/components/ui/icons.tsx`)

Стрелки «→»/«←» (12×12, stroke 1.4), галочка «✓» (таблицы замен O4a, колонка «Доступен»), внешняя ссылка «↗» (Django Admin). Все — inline-SVG с `currentColor`.

## Коллегии и оценки (обновлённая терминология)

- Коллегии: «Нанимающиеся на работу» (c1), «Отправляющие» (c2), «Доверяющие» (c3) — названия по референсам O2a/O4 вместо старых «Партнёры и подрядчики / Собственники».
- Четвёртая колонка оценок — **«Экспресс («жёсткие перег.»)»**: способность судьи оценивать экспресс-поединки, НЕ отдельный «балл переговоров» (правило обновления 11.2026).
- Состав панели — 9 (3/3/3) по регламенту; резерв 1–3. ИИ не предлагает сократить до 7; резервный судья может заменить отсутствующего.
- Обезличенные ID судей: `JUDGE_xxx` в орг-интерфейсах, краткая форма `J_xxx` в панелях O4/O4a/O5.

## Сетка и адаптивность

- **Участник** — мобильный поток 390px: колонка до 430px, центрируется на десктопе (`ParticipantLayout`).
- **Организатор** — десктопный поток 1280px: контент до 1320px, таблицы с фиксированными ширина колонок, до 720px — горизонтальный скролл (`OrganizerLayout`).
- Глобальная шапка сайта (`SiteLayout`) — единственное добавление сверх прототипа (навигация между разделами).

## Доступность

Семантические заголовки, `label` у всех полей, нативные чекбоксы с текстовой альтернативой «доступен/недоступен» в матрице O3, видимый `:focus-visible`, `aria-pressed`/`aria-current` у табов и фильтров, `role="alert"` у ошибок, `role="status"` у success-плашек.
