# USN · регистрация участников и координация судей

Проект команды **«бебе»** · Лаборатория ИИ-решений (Phoenix Education × Университет «Дубна»)
Заказчик — Универсальная школа переговоров (USN), [usnexpert.com](https://usnexpert.com/).

> **Статус: скелет решения, спринт 2.** Бизнес-правила регистрации, карта доступности и базовый
> подбор коллегий работают на демо-данных. Интеграция с API USN, LLM и фронтенд пока заглушки.

## Что делаем

У организатора соревнований по управленческой борьбе до 40 часов на турнир уходит на регистрацию,
сбор доступности судей, сборку коллегий и добор судей. Мы делаем веб-сервис поверх существующей
системы USN (Django), цель MVP — сократить эти трудозатраты до ≤ 20 ч.

- **Участник** (игрок, судья, секундант, зритель) регистрируется на турнир без дублей, с проверкой
  допустимых ролей; судья отмечает блоки доступности.
- **Организатор** видит заявки и статусы, карту доступности судей, получает от ИИ-помощника
  предложение коллегий с объяснением и варианты закрытия дефицита. Решение всегда утверждает человек.

Соревнования, роли, сроки и слоты судей уже ведутся в Django Admin заказчика — мы их **не дублируем**,
а получаем по API.

## Быстрый старт

```bash
python -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
uvicorn backend.main:app --reload
```

Открыть Swagger нашего сервиса: http://localhost:8000/docs · проверка: `GET /api/health`.

Тесты (smoke + пограничные случаи регистрации + коллегии):

```bash
pytest -q
```

Через Docker: `docker compose up --build` (сервис API + PostgreSQL на будущее).

## Что работает / что заглушка

| Компонент | Состояние |
|---|---|
| Правила регистрации: одна роль, кроме Игрок + Секундант; секундант только в классике; сроки по ролям; дубли → редактирование; согласия | ✅ работает, покрыто тестами |
| Статусы заявки (Получена / Подтверждена / Отклонена / Отозвана; резерв — вне MVP) | ✅ базово |
| Карта доступности судей по блокам | ✅ |
| Подбор коллегий для поединка (9 = 3/3/3, экспресс 5 по баллу «жёсткие переговоры»; резерв; конфликт по школе, USN нейтральна) | ✅ жадная версия; бэктест `data/backtest_collegia.py`; оптимизация на турнир — спринт 4 |
| Варианты закрытия дефицита и объяснения | ⚠️ шаблонные, LLM — спринт 3 |
| Анонимизация ПДн перед LLM | ✅ модуль, без БД |
| Вход по email с кодом | ⚠️ коды в памяти, письма в лог |
| API USN | ⚠️ `MockUSNClient`; `HttpUSNClient` — ждём доступ к стенду и сверку Swagger |
| БД PostgreSQL | ⏳ спринт 3 |
| Фронтенд | ⏳ спринт 3 по [экранам в Figma](docs/screens.md) |
