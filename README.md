> обращается к FastAPI. Каталог можно читать с dev API USN, заявки и профили пока хранятся локально.

Заказчик — Универсальная школа переговоров (USN), [usnexpert.com](https://usnexpert.com/).

## Что делаем

У организатора соревнований по управленческой борьбе до 40 часов на турнир уходит на регистрацию,
сбор доступности судей, сборку коллегий и добор судей. Мы делаем веб-сервис поверх существующей
системы USN (Django), цель MVP — сократить эти трудозатраты до ≤ 20 ч.

- **Участник** (игрок, судья, секундант, зритель) регистрируется на турнир без дублей, с проверкой
  допустимых ролей; судья отмечает блоки доступности.
- **Организатор** видит заявки и статусы, карту доступности судей, получает от ИИ-помощника
  предложение коллегий с объяснением и варианты закрытия дефицита. Решение всегда утверждает человек.

Соревнования, роли, сроки и слоты судей уже ведутся в Django Admin заказчика — мы их **не дублируем**,
а получаем по API.

## Быстрый старт

```bash
python -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
uvicorn backend.main:app --reload
```

Открыть Swagger нашего сервиса: http://localhost:8000/docs · проверка: `GET /api/health`.

Для входа в кабинет организатора задайте `ORGANIZER_PASSWORD` в окружении перед запуском
бэкенда (или в локальном `.env` при запуске через `--env-file .env`).
Логин по умолчанию — `organizer@usn.demo`. Без пароля вход в кабинет отключён.

Тесты (smoke + пограничные случаи регистрации + коллегии):

```bash
pytest -q
```

Через Docker: `docker compose up --build` (сервис API + PostgreSQL на будущее).

## Чтение с dev-стенда USN

Скопируйте `.env.example` в `.env`, выставьте `USN_MODE=http` и заполните
`USN_API_USER` и `USN_API_PASSWORD` данными Basic Auth для стенда. В `USN_API_URL`
указывается HTTPS URL до `/api`. Запуск из корня репозитория:

```powershell
python -m uvicorn backend.main:app --env-file .env
```

`GET /api/competitions` отдаёт турниры с открытыми ролями. Карточка
`GET /api/competitions/{id}` дополнительно отдаёт дни (`days`), поединки (`games`)
и отдельные блоки доступности судей (`availability_blocks`), включая число свободных мест.
Сроки регистрации стенд не отдаёт, поэтому в ответе `deadlines` пустой. Время поединков и слотов трактуется как UTC по контракту стенда.

Адаптер отправляет в USN только GET. Профили, заявки и их статусы в режиме `http`
хранятся в памяти, а код входа выводится в лог FastAPI. Ошибка чтения стенда возвращает
`502`. Для полностью локального демо выставьте `USN_MODE=mock`.

### Репетиция показа

В PowerShell перед запуском FastAPI задайте `$env:USN_MODE = 'mock'` и
`$env:USN_REVIEW_DEMO = '1'`, а также пароль организатора, как описано выше.
Откройте «Кубок Вызова · Классика (демо)». Для регистрации нового судьи выберите
первый блок. На экране входа кнопки «Демо: игрок» и «Демо: судья»
подставляют учебную почту, а после входа анкета уже заполнена. Код входа смотрите
в логе FastAPI. Для классики сначала подайте заявку игрока, затем откройте
«Стать секундантом» в «Моей заявке». Заявки появляются в кабинете после обновления страницы или входа организатора.

В архиве «Дубна_ USN соревнования (1).xlsx», лист «КУБОК ВЫЗОВА 2026 классика»,
взяты этапы и расписание 28 поединков. Для репетиции даты перенесены на март 2030,
одно пересечение времени исправлено. Все анкеты, контакты, оценки 36 судей и
дефицит двух судей на финале учебные. Поединки демо считаются последовательными.

В кабинете откройте «Проблемные поединки» → «Помочь» → «Применить вариант».
Последний шаг моделирует согласие предложенных судей, обновляет их доступность
и пересчитывает коллегии. Вкладка «Коллегии» позволяет сформировать предложение,
посмотреть объяснение, заменить судью резервным и утвердить результат в текущем экране.
Для повторной записи перезапустите FastAPI: заявки и доступность сбросятся к исходным данным.
