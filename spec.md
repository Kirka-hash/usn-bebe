# Спецификация предметной области

Источники: ТЗ USN, Правила ЧМ 2026, ответы заказчика (21.10, 26.10, 08.11), бизнес-логика М. Матвеева.

## Роли
| Роль | Код | Особенности |
|---|---|---|
| Игрок | `player` | в командном формате указывает напарника |
| Судья | `voter` | отмечает блоки доступности; коллегию не выбирает и не видит |
| Секундант | `adviser` | только классика; может секундировать нескольким игрокам; не себе |
| Зритель | `viewer` | без доп. полей; игрокам и судьям регистрироваться зрителем не нужно |
| Организатор / Главный арбитр | — | одна роль с одинаковыми правами |

**Совмещение:** в одном соревновании одна роль, единственное исключение — Игрок + Секундант другого игрока.

## Форматы
| Формат | Судьи на поединок | Коллегии | Резерв | Секунданты |
|---|---|---|---|---|
| Классика | 9 (3/3/3) — задано регламентом, ИИ не сокращает | Нанимающиеся · Отправляющие · Доверяющие | резервный судья может судить за недостающую коллегию | да |
| Экспресс | 5 | Отправляющие (балл — «жёсткие переговоры») | 1 | нет |
| Командный | 9, команда — 2 игрока | 3 коллегии | до 3 | нет |

## Инварианты регистрации
- Повторная регистрация в той же роли открывает существующую заявку (не дубль).
- Роль закрыта или дедлайн прошёл — только просмотр.
- Сроки по умолчанию: игроки — до жеребьёвки, судьи/секунданты/зрители — за 2 дня до турнира.
- Обязательные поля: Фамилия, Имя, Страна, Город; три согласия (правила, ПДн, фото/видео).
- Судья отмечает минимум один блок доступности.

## Статусы заявки
`Получена → Подтверждена | Отклонена`, участник может `Отозвать`.
«Получена» — заявка прошла серверную проверку и API USN подтвердил сохранение.
Резерв в MVP не входит: организатор работает с ним вручную в Telegram (заказчик, 10.11).
Открыто: сбрасывает ли правка подтверждённой заявки статус.

## Коллегии (ИИ-помощник, задача «А»)
Критерии: доступность по блокам; баллы экспертов 1–3 по коллегиям (среднее ОС и КС — решение команды; в экспрессе — столбец «жёсткие переговоры»);
конфликт интересов (одна школа/клуб — это же покрывает тренер–ученик; напарник; USN — не конфликт);
на финалы — сильнейшие. Пересчёт при новых заявках. Утверждает человек.

## Дефицит (задача «Б»)
Найти незаполненные/рискованные поединки → 2–3 варианта: соседний блок, незарегистрированные
опытные судьи, резервный судья за недостающую коллегию → кандидаты с причиной и текст приглашения.
Сокращать состав ИИ не предлагает — количество судей определено регламентом (заказчик, 10.11).
