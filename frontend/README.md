# Frontend (спринт 3)

React + адаптивная вёрстка в фирменном стиле USN. Экраны и переходы — [docs/screens.md](../docs/screens.md)
и прототип в Figma. Приоритет — кабинет организатора (O1–O5), затем экраны участника (U1–U9).

Бэкенд для разработки: `uvicorn backend.main:app --reload`, Swagger — http://localhost:8000/docs.
