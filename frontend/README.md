# Фронтенд USN

React + Vite + TypeScript. Экраны участника и организатора используют **наш FastAPI** по `/api`.
Vite проксирует `/api` на `http://127.0.0.1:8000`; при другом адресе задайте `VITE_API_URL`.
Ключи и пароль dev API USN во фронтенде не нужны.

## Локальный запуск

Из корня репозитория: `uvicorn backend.main:app --reload`.
Из `frontend/`: `npm ci`, затем `npm run dev`. Откройте `http://localhost:5173`.
Проверка сборки: `npm run build`. При запущенных API и Vite: `npm run verify`.

## Что работает

- Турниры, карточка, заявки, профиль, доступность и статусы читаются из FastAPI.
- Участник получает email-код через `/auth/request-code` и входит через `/auth/verify`.
  В текущей backend-заглушке письмо выводится в лог сервера, а сессия хранится в памяти процесса.
- Анкета и согласия отправляются в FastAPI; повторная заявка той же роли обновляется бэкендом.
- Командный турнир: можно указать напарника позже; второй игрок видит приглашение,
  регистрируется при необходимости, подтверждает или отклоняет его.
- Организатор видит заявки из FastAPI и меняет их статус. Создание турниров остаётся в Django Admin USN.

## Что ещё демо

- Кабинет использует отдельную сессию FastAPI. Для локального входа задайте бэкенду `ORGANIZER_PASSWORD` перед запуском. Логин по умолчанию — `organizer@usn.demo`; его можно сменить через `ORGANIZER_EMAIL`.
- Коллегии, объяснения и проблемные поединки O4/O5 используют примеры из `src/data/mock.ts`;
  для настоящих турниров нужны данные расписания и судей от USN через FastAPI.
- FastAPI хранит профили и заявки в памяти в обоих режимах. После перезапуска сервера они исчезают.
  В режиме `http` FastAPI читает соревнования, расписание и блоки доступности судей с dev API USN.
- `frontend/docs/` описывает первоначальный демопрототип Тимура; актуальные ограничения указаны здесь.
