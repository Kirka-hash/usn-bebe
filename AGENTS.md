# AGENTS.md — правила для ИИ-ассистентов

1. **Не меняем систему заказчика.** Ядро Django USN и Django Admin не трогаем и не дублируем
   (соревнования, роли, сроки, слоты). Все обращения — только через `backend/integrations/usn/`.
2. **ПДн не уходят во внешние LLM.** Любой текст для LLM проходит через `ai_advisor/anonymizer.py`:
   только токены `JUDGE_xxx` / `PLAYER_xxx`, без ФИО, email, Telegram.
3. **ИИ не назначает судей сам.** Подбор коллегий — детерминированный код (`judging/collegia.py`),
   LLM только объясняет и пишет тексты. Каждое предложение содержит объяснение.
4. **Блок доступности судьи ≠ слот поединка.** Не смешивать.
5. **Составы и резерв не хардкодить** — их задаёт организатор (кроме допустимых схем 9/7/5 из правил).
6. **После каждого изменения — `pytest -q`.** Обязательные пограничные случаи: повторная регистрация,
   Игрок + Секундант, один секундант на нескольких игроков, закрытая роль / дедлайн,
   секундант вне классики, напарник только в командах, правка подтверждённой заявки.
7. Стек: Python 3.11+, FastAPI, Pydantic v2, pytest; фронтенд — React. Язык интерфейса и сообщений — русский.
